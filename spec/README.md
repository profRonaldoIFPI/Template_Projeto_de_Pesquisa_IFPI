# Diretório de Especificações (`spec/`)

Este diretório contém os arquivos de especificação técnica e funcional do modelo de Projeto de Pesquisa do Instituto Federal do Piauí (IFPI).

## Conteúdo do Diretório

- **`specification.md`**: Documento contendo as especificações técnicas, mapeamento de comandos LaTeX, validação de regras de margens, estilos de citações (NBR 10520:2023) e compatibilidade com normas ABNT/IFPI.
- **`estrutura-projeto.md`**: Detalhamento da tabela comparativa e estrutura lógica do projeto de pesquisa exigido para o IFPI Campus Floriano (NBR 15287).

---

## Orientações sobre Alterações

> [!IMPORTANT]
> Este diretório serve para fins de **desenvolvimento, especificação técnica e garantia de qualidade (QA)** do repositório. O conteúdo aqui contido não interfere na compilação do seu documento LaTeX ou no PDF final do seu projeto.
